# 普罗米修斯历法

## 一、基本规则

- 一日：48地球小时。
- 一年：以普罗米修斯绕恒星公转一周为准。
- 平均太阳年：236.55个普罗米修斯日。
- 一年：12个月。
- 大月：20日。
- 小月：19日。
- 一周：6日，其中前4日为工作日，后2日为休息日。
- 星期连续计数，不因月份或年份结束而重新开始。

## 二、年份周期

历法以5年为一个小周期，排列顺序为：

**长年、短年、短年、长年、短年**

该5年周期连续重复4次，构成一个完整的20年大周期。

## 四、闰年规则

1. 从元年开始，每逢20的整数倍年份为闰年。
2. 每个闰年增加3个闰日。
3. 闰日不单独组成月份，而是分别加入该年最后三个小月，每个小月增加1日。
4. 闰年仍然只有12个月，不设置第13个月。
5. 每个20年周期的最后一年必定为短年，因此闰年为闰短年。

## 五、20年周期统计


| 项目         | 数量      |
| --- | ---: |
| 长年         | 8年      |
| 普通短年       | 11年     |
| 闰短年        | 1年      |
| 大月总数（未计闰日） | 184个    |
| 小月总数（未计闰日） | 56个     |
| 闰日总数       | 3日      |
| 周期总天数      | 4731日   |
| 平均年长       | 236.55日 |


周期总天数计算：

- 8个长年：8 × 237 = 1896日
- 11个普通短年：11 × 236 = 2596日
- 1个闰短年：239日

**20年总计：1896 + 2596 + 239 = 4731日。**

平均每年：

4731 ÷ 20 = 236.55日。

因此，该历法的20年周期总长度与设定的平均太阳年完全一致。

## 六、节气

- 一年设置24个节气。
- 沿用传统二十四节气名称及排列顺序。
- 以太阳视黄经每增加15°作为进入下一个节气的天文标准。
- 官方节气以北半球为参照。
- 冬至暂定以第一年12月10日作为初始参考时刻。
- 节气的实际日期随太阳运行及民用历法的闰年调整而变化，不保证每年固定在同一月日。
- 平均节气间隔约为9.85625个普罗米修斯日。

## 七、周期重置

每20年构成一个完整历法周期。

周期结束后，下一年重新进入下一轮五年大小年排列：

**长年 → 短年 → 短年 → 长年 → 短年**

星期继续连续计数，不随20年周期结束而重置。
